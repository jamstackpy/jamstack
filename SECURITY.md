# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.0.x   | Yes       |
| < 2.0   | No        |

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Do not open a public issue.

Use GitHub's private vulnerability reporting:
https://github.com/jamstackpy/jamstack/security/advisories/new

Include the affected version, a minimal reproduction, and the impact.

You can expect an acknowledgement within 72 hours and a status update
within 14 days. Once a fix is ready, a patched release is published and
the advisory is made public with credit, unless you prefer to stay
anonymous.
